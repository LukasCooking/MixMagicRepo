# MixMagicRepo
🏦 PKO XP: Gaming – Finansowa Podróż
🚀 Overview

Finansowa Podróż to moduł edukacyjny dla aplikacji IKO, który łączy:

szybkie quizy (mikro-nauka)
system progresu (Portfel Wartości)
symulację decyzji finansowych (AI-driven experience)

Celem jest umożliwienie użytkownikom nauki finansów poprzez krótkie interakcje i realne scenariusze decyzyjne.

💡 Problem

Edukacja finansowa:

jest zbyt długa i pasywna
przegrywa z krótkimi formami contentu
nie pokazuje realnych konsekwencji decyzji

👉 Użytkownicy podejmują decyzje finansowe bez pełnego zrozumienia.

🎯 Solution

Tworzymy doświadczenie inspirowane grami, które działa w dwóch warstwach:

🔹 1. Micro-learning (Quizy)
krótkie pytania (1–3 dziennie)
natychmiastowy feedback
szybki progres
🔹 2. Portfel Wartości
odznaki i poziomy
rozwój wiedzy w obszarach finansowych
wizualizacja progresu
🔹 3. Finansowa Podróż (AI Simulation)
użytkownik podejmuje decyzje finansowe
obserwuje wpływ czasu i inflacji
analizuje skutki swoich wyborów

👉 Nauka przez doświadczenie, nie teorię

🎮 Core Loop
Quiz → szybka odpowiedź
Feedback → nauka
Reward → progres
Portfel Wartości → motywacja
Finansowa Podróż → głębia
Powrót → utrwalenie wiedzy
🤖 Role of AI

AI pełni rolę doradcy:

tłumaczy konsekwencje decyzji
prowadzi użytkownika przez scenariusz
buduje kontekst edukacyjny
👤 User Journey
Użytkownik wykonuje szybki quiz
Zdobywa XP i odznaki
Odkrywa Portfel Wartości
Rozpoczyna Finansową Podróż
